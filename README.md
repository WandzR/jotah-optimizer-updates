# Jotah Optimizer — atualizações para Windows

Este repositório publica os instaladores oficiais e os arquivos usados pela atualização automática do Jotah Optimizer.

## Downloads

[Baixar o instalador mais recente para Windows x64](https://github.com/WandzR/jotah-optimizer-updates/releases/latest/download/Jotah-Optimizer-Setup.exe).

Versões e notas estão na [página de Releases](https://github.com/WandzR/jotah-optimizer-updates/releases). O endereço de download acima acompanha sempre a versão estável mais recente.

Após a primeira instalação pelo instalador oficial, o aplicativo verifica novas versões e baixa a atualização em segundo plano. A instalação aguarda o término das operações do aplicativo e reinicia o Jotah.

Cada release contém o instalador com versão, uma cópia idêntica com nome fixo, `latest.yml`, `.blockmap` e `jotah-release.json`. O aplicativo verifica a assinatura criptográfica do projeto e o conteúdo do arquivo antes de instalar uma atualização.

Na primeira instalação, o Windows pode mostrar editor desconhecido enquanto o certificado Authenticode do editor não estiver configurado.

O código-fonte, as credenciais de pagamento e os dados dos clientes são mantidos fora deste repositório.
